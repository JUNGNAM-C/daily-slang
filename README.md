# 오늘의 신조어 (모바일 웹앱 / PWA)

게임기 모양의 화면에서 매일 신조어 2개를 보여 주는 앱입니다.
스마트폰 홈 화면에 설치해서 앱처럼 쓸 수 있고, 새 단어는 AI가 웹 검색으로 매일 2개씩 찾아 추가합니다.

## 조작법

| 버튼 | 동작 |
|---|---|
| 빨간 B 버튼 | 오늘의 신조어 첫 번째 |
| 빨간 A 버튼 | 오늘의 신조어 두 번째 |
| 십자키 위 | 유래 |
| 십자키 아래 | 예문 |
| 십자키 왼쪽 | 10년 전 유사어 → (한 번 더) 20년 전 → (한 번 더) 30년 전. 그 시절 같은 뜻으로 쓰이던 말 |
| 십자키 오른쪽 | 반대어 (유사어 쪽에서는 오른쪽으로 되돌아옴) |
| 초록 버튼 (JP/CN) | 오늘의 일본어 또는 중국어 신조어 (한국어 신조어와 별개, 누를 때마다 무작위) |
| 노란 버튼 (EN) | 오늘의 영어 신조어. 한국어와 똑같이 뜻 화면에서 시작하고 십자키 조작도 같음. 한글 발음 표기 포함 |
| 십자키 가운데 | 홈(시작) 화면으로 돌아가기 (PC는 Esc) |
| 회색 SHARE | 메모장이 열려 있으면 메모를, 아니면 지금 보는 신조어를 카드 그림(JPG)으로 만들어 다른 앱으로 공유 (공유를 지원하지 않는 브라우저에서는 JPG로 저장) |
| 회색 MEMO | 화면 크기 메모장 열기·닫기. 적는 대로 이 기기에 자동 저장 (PC는 Esc로 닫기) |

화면 배치는 `30년 전 ← 20년 전 ← 10년 전 ← [단어(뜻)] → 반대어` 이고 위는 유래, 아래는 예문입니다. 십자키로 이동하고 반대 방향을 누르면 돌아옵니다. PC에서는 방향키, A(또는 X), B(또는 Z) 키로도 조작됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 전체 (오늘 날짜에 맞는 단어를 골라 보여 줌) |
| `fonts/` | 화면 글꼴 Mona 4종(SIL OFL 1.1, `OFL-NOTICE.txt` 참고) |
| `slang_common.py` | 두 생성 스크립트가 함께 쓰는 도우미 (10·20·30년 전 유사어·반대어 정리와 채우기) |
| `words.json` | 단어 목록. 처음에는 20개가 들어 있고, 매일 2개씩 늘어남 |
| `generate.py` | 웹 검색 + AI로 오늘의 새 단어를 만들어 `words.json`에 추가 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 설치·오프라인 동작용 파일 |
| `.github/workflows/daily.yml` | GitHub에서 매일 자동으로 `generate.py`를 돌리는 설정 |

앱은 한국 시간 기준 오늘 날짜가 붙은 단어를 최대 2개 보여 주고(A, B 버튼), 모자라면(생성이 실패한 날 등) 기본 20개 중에서 날짜에 따라 돌려 가며 채웁니다. 그래서 자동 생성이 하루 멈춰도 화면이 비지 않습니다.

## 1단계. 내 컴퓨터에서 먼저 열어 보기

앱은 파일을 그냥 더블클릭하면 단어 목록을 못 불러옵니다(브라우저 보안 규칙). 간단한 로컬 서버를 켜서 봅니다.

1. 이 폴더(`index.html`이 있는 폴더)를 엽니다.
2. 폴더 빈 곳에서 Shift 키를 누른 채 오른쪽 클릭하고 **"여기에 PowerShell 창 열기"** 또는 **"터미널에서 열기"**를 선택합니다.
3. 열린 검은(또는 파란) 창에 아래를 입력하고 Enter를 누릅니다.

```powershell
python -m http.server 8000
```

- 성공하면 `Serving HTTP on :: port 8000 (http://[::]:8000/) ...` 같은 문장이 나오고 커서가 멈춥니다. 정상입니다. 이 창은 닫지 말고 그대로 둡니다.
- `'python'은(는) 내부 또는 외부 명령...이 아닙니다`가 나오면 파이썬이 설치되지 않았거나 PATH에 없는 겁니다. https://www.python.org/downloads/ 에서 설치하고, 설치 첫 화면에서 **"Add python.exe to PATH"**를 꼭 체크한 뒤 창을 새로 열어 다시 시도하세요. `py -m http.server 8000`으로 시도해도 됩니다.
- `OSError: [Errno 10048]`처럼 포트가 사용 중이라는 오류가 나오면 `8000`을 `8080`으로 바꿔 다시 실행합니다.

4. 브라우저 주소창에 `http://localhost:8000` 을 입력하면 오늘의 신조어 화면이 보입니다.
5. 끝낼 때는 PowerShell 창에서 Ctrl+C를 누릅니다.

## 2단계. 새 단어 자동 생성 준비 (API 키)

1. https://console.anthropic.com 에 로그인해 **API Keys**에서 키를 새로 만들고 복사합니다. (`sk-ant-...`로 시작. 남에게 보이거나 코드에 적으면 안 됩니다.)
2. PowerShell에서 아래 명령으로 패키지를 설치합니다. (같은 폴더에서 실행)

```powershell
pip install -r requirements.txt
```

- 성공하면 마지막에 `Successfully installed anthropic-...` 가 나옵니다.
- `'pip'은(는) ...` 오류가 나오면 `python -m pip install -r requirements.txt`로 실행합니다.

3. 현재 PowerShell 창에서만 쓰는 임시 설정으로 키를 등록합니다. (창을 닫으면 사라지므로 매번 입력해야 합니다.)

```powershell
$env:ANTHROPIC_API_KEY = "여기에_복사한_키"
```

입력해도 아무 메시지가 나오지 않는 것이 정상입니다.

## 3단계. 오늘의 단어 만들어 보기

먼저 파일을 건드리지 않는 시험 실행으로 확인합니다.

```powershell
python generate.py --dry-run
```

- 성공하면 `[1/3] 신조어를 검색하는 중…` 다음에 `선정된 단어:`와 함께 단어·뜻·예문이 JSON으로 출력되고, 마지막에 `(--dry-run) words.json은 수정하지 않았습니다.`가 나옵니다. 1~2분 걸릴 수 있습니다.
- `ANTHROPIC_API_KEY 환경변수가 설정되어 있지 않습니다`: 2단계의 3번을 같은 창에서 다시 실행하세요.
- `authentication_error` 또는 `401`: 키를 잘못 복사했거나 만료된 겁니다. 새 키로 바꿉니다.
- `credit balance is too low`: Anthropic Console에서 크레딧을 충전해야 합니다.
- `실패: 이미 있는 단어가 다시 나왔습니다`가 1~2번 나오다가 성공하는 것은 정상입니다(자동 재시도). 3번 모두 실패하면 잠시 뒤 다시 실행하세요.

결과가 마음에 들면 실제로 저장합니다.

```powershell
python generate.py
```

마지막에 `words.json에 저장했습니다. (총 ...개)` 가 단어마다(하루 2번) 나오면 성공이고, 브라우저에서 새로고침하면 오늘 단어가 바뀝니다. 같은 날 다시 실행하면 `오늘(날짜) 단어는 이미 있습니다`라고 알려 주고 아무것도 바꾸지 않습니다. 오늘 단어를 다시 뽑고 싶으면 `python generate.py --force`를 씁니다.

## 4단계. 매일 자동으로 돌리기 + 인터넷에 올리기 (GitHub)

내 컴퓨터를 켜 두지 않아도 매일 아침 자동으로 갱신되게 하는 방법입니다. 무료 GitHub 계정이면 됩니다.

1. GitHub에서 새 저장소(Repository)를 만들고, 이 폴더의 모든 파일(숨김 폴더 `.github` 포함)을 올립니다.
2. 저장소의 **Settings → Secrets and variables → Actions → New repository secret**에서 이름을 `ANTHROPIC_API_KEY`, 값을 API 키로 해서 저장합니다.
3. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 설정하고 Save를 누릅니다. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소가 생깁니다.
4. **Actions 탭 → 오늘의 신조어 자동 갱신 → Run workflow**를 눌러 한 번 시험 실행합니다. 초록색 체크가 뜨고 저장소의 `words.json`에 새 항목이 생기면 성공입니다. 이후에는 매일 한국 시간 오전 6시쯤 자동 실행됩니다.
   - 빨간 X가 뜨면 해당 실행을 눌러 로그를 보세요. `ANTHROPIC_API_KEY` 관련 문구면 2번 설정을 확인합니다.

## 5단계. 스마트폰에 설치

- **안드로이드(크롬)**: 위 주소로 접속해 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**.
- **아이폰(사파리)**: 접속해 공유 버튼 → **홈 화면에 추가**.

## 알아 두면 좋은 점

- 오늘의 단어 아래에 반대 뜻·비슷한 뜻·비슷한 구성의 관련 단어가 "함께 알아두면 좋아요"로 붙습니다. 출처에서 확인되는 것만 넣고, 확인되지 않으면 이 영역은 나오지 않습니다.
- 신조어의 뜻과 유래는 AI가 웹 검색 결과를 요약한 것이라 틀리거나 커뮤니티마다 다를 수 있습니다. 앱 안에 "출처 보기" 버튼이 있고, 뜻이 갈리는 단어는 "참고"에 적어 둡니다.
- 예문은 AI가 지어낸 문장입니다. 출처에 있는 문장이 아닙니다.
- 기본으로 들어 있는 20개는 2026년 뉴스·블로그 정리글에서 모은 것입니다.
- 인스타그램 같은 SNS 내부 데이터는 외부에서 가져올 수 없어서, 웹에 공개된 글을 수집원으로 씁니다.
- AI 모델 이름은 `generate.py`의 `MODEL` 값(기본 `claude-sonnet-5-5`)이고, 환경변수 `SLANG_MODEL`로 바꿀 수 있습니다. 호출 비용은 하루 한 번 검색·요약하는 수준이라 작은 편입니다.
- 앱 파일(`index.html` 등)을 고쳤는데 휴대폰에 반영되지 않으면 `sw.js` 맨 위의 `VERSION = 'v1'`을 `'v2'`처럼 올려서 다시 배포하세요.


## 외국어 신조어 (별개 시스템)

- 한국어 신조어(`words.json`, `generate.py`)와 완전히 따로, `foreign.json`과 `generate_foreign.py`가 영어·일본어·중국어를 각각 하루 1개씩 찾아 뜻·유래·예문·**한글 발음**을 정리합니다.
- 자동 실행은 `.github/workflows/foreign.yml`(매일 한국 시간 6시 30분)입니다. 수동 실행은 Actions 탭 → "오늘의 외국어 신조어 자동 갱신" → Run workflow, 내 컴퓨터에서는 `python generate_foreign.py --dry-run`으로 시험합니다.
- 날짜가 없는 항목은 기본 목록이고, 오늘 날짜가 붙은 새 단어가 없으면 이 기본 목록을 날짜에 따라 돌려 보여 줍니다.

- 10년 전·20년 전·30년 전 유사어와 반대어는 새 단어를 만들 때 함께 찾고, 매 실행마다 아직 확인하지 않은 기존 단어를 4개씩(최근 날짜 단어 먼저) 채웁니다. 출처(https)가 확인되지 않은 항목은 버리므로 비어 있는 시기도 있습니다. 개수는 `--enrich-limit 숫자`, 건너뛰기는 `--no-enrich`입니다. 외국어 단어도 같은 방식으로 한글 발음과 함께 채워집니다.

## 출처 원칙 (출처 없는 자료는 반입 금지)

- 단어, 10·20·30년 전 유사어, 반대어, 외국어 단어 모두 **출처 주소(https)가 없으면 저장하지 않습니다.**
- 출처 주소는 AI가 웹 검색으로 실제로 받아 본 페이지 주소여야 합니다. AI가 주소를 짐작하거나 지어낸 경우(검색 결과에 없는 주소)는 그 항목을 버립니다. 이 검사는 `slang_common.py`의 `search_urls`·`source_ok`가 합니다.
- 확인되지 않으면 억지로 채우지 않고 화면에 "출처에서 확인된 ○○이 아직 없어요"라고 표시합니다.
